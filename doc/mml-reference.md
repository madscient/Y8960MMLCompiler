# MML リファレンス

**この文書は、`y8mmlc` が受け付ける MML のコマンドとその意味。** トラック行に
書く中身がこれにあたる。ファイル全体の書き方（トラック行、`#assign` などの
メタコマンド、行の連結）は [`mml-source.md`](mml-source.md) にある。

MML は Y8960 BASIC Extension の MML と同じもので、同じ MML は同じ演奏データに
なる。

## 書き方の約束

- **大文字と小文字は区別しない。** `CDE` と `cde` は同じ
- **空白はどこでも読み飛ばす。** コマンドや数の途中でもよい。`L 1 6` は `L16`、
  `| :` は `|:`、`( D C )` は `(DC)` と同じ。同じトラックの行の切れ目も空白と
  同じに扱う
- **数は10進で書く。** `$` を付けると16進で、**`$` の後は必ず2桁**（`$00`〜`$FF`）。
  `A`〜`F` は16進の桁でも音名でもあるので、2桁で数え終える。`Y$20,$0FCDE` は
  「レジスタ 20H に 0FH を書き、C D E を鳴らす」になる。`$4` のような1桁はエラー
- **数を書くところには、`#define` で付けた名前を `=名前;` で書ける**
  （[名前の参照](#名前の参照-名前-と-x名前)）
- **範囲の外の数はエラーになる。** 例外はこの文書の中でその都度書いてある

## トラックの種類

MML の書き方は、トラックを `#assign` で割り当てたチャンネルで変わる。

| チャンネル | 書き方 |
|---|---|

| OPLLEX1・OPLLEX2・OPL2EX1・OPL2EX2 のチャンネル 10 | [リズム音用 MML](#リズム音用-mml) |
| それ以外 | この文書のほかの節に書いた、ふつうの MML |

## コマンド一覧

ふつうの MML のコマンド。*n* は数。

| コマンド | 意味 | 範囲 | 既定 |
|---|---|---|---|
| `A`〜`G` | 音符。後ろに `+` `#`（半音上げる）か `-`（半音下げる）、長さ、付点を書ける | 長さ 0〜96 | 長さは `L` |
| `R`*n* | 休符 | 0〜96 | 長さは `L` |
| `N`*n* | 番号で高さを指定する音符。オクターブを変えない | 0〜96 | |
| `O`*n* | オクターブ | 1〜8 | 4 |
| `>` `<` | オクターブを1つ上げる・下げる | | |
| `L`*n* | 長さを省いた音符と休符の長さ | 1〜96 | 4 |
| `.` | 直前の長さを 1.5 倍する。重ねられる | | |
| `V`*n* | 音量 | 0〜15 | 8 |
| `@V`*n* | 音量を細かく | 0〜127 | 71 |
| `T`*n* | テンポ（1分あたりの四分音符の数） | 32〜255 | 120 |
| `Q`*n* | 音符の長さのうち鳴らす割合（8分の *n*） | 1〜8 | 8 |
| `@`*n* | 音色。意味は音源で違う（[音色 `@n`](#音色-n)） | 音源による | 0 |
| `@W`*n* | 音を鳴らしたまま待つ | 1〜96 | 長さは `L` |
| `&` | 前後の音符をつなぐ（タイ・レガート） | | |
| `P`*n* | ピッチベンド（セント） | −1200〜1200 | 0 |
| `@P`*n* | ピッチベンドを今の値に足す（セント） | −1200〜1200 | |
| `~`*n* | 次の音符へ滑らかに移る（ポルタメント） | −1200〜1200、省略可 | |
| `{` … `}`*n* | 連符 | 1〜96 | `L` |
| `S`*n* | SSGS のエンベロープの形 | 0〜15 | |
| `M`*n* | SSGS のエンベロープの周期 | 1〜65535 | |
| `I`*n* | SSGS の定位 | 0〜15 | 8 |
| `Y`*r*`,`*d*[`,`*m*] | 音源のレジスタに直接書く | 音源による | |
| `X`*名前*`;` | `#define` で付けた MML をその場に展開する | | |
| `\|:` … `:\|`*n* | 繰り返し | 0〜255 | 1 |
| `[`*n* … `]` | 繰り返しの *n* 回目だけ演奏する区間 | 0〜255 | |
| `(*)`*n* `(DS)`*n* | セーニョ、ダルセーニョ | 0〜3 | 0 |
| `(TC)`*n* `(CODA)` | トゥコーダ、コーダ | 0〜255 | 2 |
| `(FINE)`*n* `(DC)` | フィーネ、ダカーポ | 0〜255 | 2 |

**時間を取るのは音符・休符・`N`・`@W` だけ。** ほかのコマンドは、書いた位置で
すぐ効いて時間を取らない。

## 音符と休符

### 臨時記号

臨時記号は**オクターブの中で折り返す。** `C-` は同じオクターブの `B`、`B+` は
同じオクターブの `C` になる。オクターブは変わらない。

### 長さ 0 の音符と `R0`

- **長さ 0 の音符は、鳴らし始めるだけで時間を取らない。** 続けて `@W` や
  `P` などで、1つの音の中で音程や音量を動かせる
- **`R0` は、音を止めるだけで時間を取らない**

```
O4 C0 @W8 P100 @W8 P200 @W8 R0
```

`C0` で鳴らし始め、8分音符ずつ待ちながら 100、200 セントと上げ、`R0` で止める。
全体の長さは8分音符3つぶん。

**時間を進めずに次の音符は置けない。** 長さ 0 の音符のあと、次の音符までに
`@W` か長さのある休符を挟まないとエラーになる。同じ瞬間に2度鳴らし始めても
意味が無いため。

```
C0 D0       ; エラー
C0 R0 D0    ; エラー（R0 は時間を取らない）
C0 @W8 D0   ; よい
```

### 長さを省いた休符

**`R` の長さを省くと `L` の長さになる。** `L8 R` は8分休符。

### `N`*n* ―― 番号で高さを指定する

番号は「オクターブ × 12 ＋ 半音」（半音は C が 0、B が 11）。`N48` が `O4 C`、
`N96` が `O8 C`。`N` はオクターブを変えないので、`N` のあとの音名は元の
オクターブのまま鳴る。

### オクターブの端

`O8` で `>`、`O1` で `<` を書いても、何も起きない。エラーにはならない。

## 音長と連符

### 長さの数え方

演奏の時間は **tick** で数え、**四分音符が 48 tick**、全音符が 192 tick。
*n* 分音符は 192 を *n* で割った tick で、**端数は切り捨てる**。

| 書き方 | tick |
|---|---|
| `C4` | 48 |
| `C8` | 24 |
| `C7` | 27（192 ÷ 7 の切り捨て） |
| `C96` | 2 |
| `C4.` | 72 |
| `C4..` | 84 |

**付点は、1つ付けるたびに「直前に足した分の半分」を足す。** `C4..` は
48 ＋ 24 ＋ 12。`L` にも付点を書ける（`L8.`）。

### 連符 `{ }`*n*

`{` と `}` で囲んだ音符を、*n* 分音符ぶんの長さに収める。*n* を省くと `L` の長さ。

```
{CDE}4      ; 四分音符を3等分した長さで C D E
```

- **囲んだ中で数えるのは、音名・`R`・`N` だけ。** その数で長さを割った
  （切り捨てた）ものが、長さを省いた音符の長さになる
- **自分で長さを書いた音符は、その長さのまま。** `{C8DE}4` の C は8分音符で、
  D と E が四分音符の3等分
- **長さを省いた `R` と `@W` も、割った長さになる。** ただし `@W` は数えない
  ので、そのぶん連符は *n* 分音符より長くなる。`&` も数えない
- 割った長さが 2 tick に満たないとエラー。`{CDE}32` は通り、`{CDE}33` は通らない
- 連符の長さにも付点を書ける（`{CDE}4.`）
- 入れ子にはできない。中に音符が1つも無いとエラー。`{` と `}` はそのトラックの
  中で対になっていること

## 音量・テンポ・音の長さの割合

### `V`*n* と `@V`*n*

どちらも同じ音量を決める。`V`*n* は `@V` の *n* × 8 ＋ 7 と同じ（`V8` は `@V71`、
`V15` は `@V127`）。**あとに書いたほうが効く。**

### `T`*n*

テンポは**トラックではなく、シーケンス全体のもの。** どのトラックで書いても
全部のトラックの速さが変わる。テンポを変えても音符の長さの比は変わらない。

### `Q`*n*

音符の長さのうち、鳴らす割合を8分の *n* で決める。**`Q8` は長さいっぱいに鳴らし、
次の音符まで止めない。** `Q` を小さくすると、音符の途中で音が止まる。
短い音符で割った長さが 0 になるときは、少なくとも 1 tick は鳴る。

## 音色 `@`*n*

音源によって意味が違う。**`@`*n* を書く前の音符は `@0` で鳴る。**
曲を繰り返すと、そのたびに `@0` から始まる。

### FM 音源（OPLLEX・OPL2EX のチャンネル 0〜8）

| *n* | OPLLEX | OPL2EX |
|---|---|---|
| 0〜63 | プリセット音色（[付録](#プリセット音色-0063)） | プリセット音色 |
| 64 | エラー | エラー |
| 65〜127 | チップ内蔵の音色（下記） | 無視される（それまでの音色のまま） |
| 128〜191 | `#voice` で作った音色 | `#voice` で作った音色 |

**OPLLEX のチップ内蔵の音色は、バンクと番号を *n* にまとめて選ぶ。**

| *n* | バンク | 番号 |
|---|---|---|
| 65〜79 | 0（OPLL） | 1〜15 |
| 81〜95 | 1（OPLL-X） | 1〜15 |
| 97〜111 | 2（OPLL-P） | 1〜15 |
| 113〜127 | 3（VRC7） | 1〜15 |

*n* − 64 の上位2ビットがバンク、下位4ビットが番号。`@80`・`@96`・`@112` は
そのバンクの番号 0 で、チップのユーザー音色を選ぶ。

**OPLLEX でプリセット音色（0〜63）と `#voice` の音色（128〜191）を鳴らすときは、
チップのユーザー音色を使う。** ユーザー音色は OPLLEX の1ブロックに1つしか
無いので、同じブロックの2つのチャンネルで違う音色を同時に鳴らすと、あとから
選んだ音色で両方が鳴る。チップ内蔵の音色（65〜127）はチャンネルごとに選べる。

1つのシーケンスが使えるプリセット音色・`#voice` の音色・SCC の波形は、
**合わせて 32 種類まで**。同じ `@`*n* を何度書いても1種類と数える。

### SCC

| *n* | 内容 |
|---|---|
| 0〜15 | プリセット波形（[付録](#プリセット波形-015)） |
| 16〜31 | `#wave` で作った波形 |

### SSGS

SSGS に音色は無いので、`@`*n* は**トーンとノイズの出力の切り替えと、
ハードウェアエンベロープを使うかどうか**をまとめて決める。*n* は 0〜255。

| ビット | 内容 |
|---|---|
| bit4〜0 | 振幅レジスタに書く値。bit4 が 1 でハードウェアエンベロープを使い、bit3〜0 が音量 |
| bit5 | トーン。**0 で鳴る** |
| bit6 | ノイズ。**1 で鳴る**（bit5 とは逆） |

**bit4 が 0 のときは bit3〜0 を書かない。** ハードウェアエンベロープを使わない
ときの音量は `V` と `@V` が持つ。

| `@`*n* | 内容 |
|---|---|
| `@0` | トーンのみ（初めの状態） |
| `@64` | トーン＋ノイズ |
| `@96` | ノイズのみ |
| `@32` | どちらも鳴らさない。音量ぶんの直流が出る |
| `@16`＋*v* | ハードウェアエンベロープ、音量 *v*（0〜15） |

切り替えはチャンネルごとに効き、同じ SSGS のほかのチャンネルは変わらない。

### DCSG

**矩形波のチャンネル（0〜2）では、`@`*n* は無視される。**

**ノイズのチャンネル（3）では、`@`*n* がノイズの高さを選ぶ。**

| `@`*n* | 内容 |
|---|---|
| `@0` `@1` `@2` | 決まった高さ。ちょうど1オクターブずつ離れていて、`@0` がいちばん高い |
| `@3` | 同じ DCSG のチャンネル 2 の周波数に従う |

`@3` のあいだは、**ノイズのチャンネルに書いた音符の高さが、チャンネル 2 の
周波数レジスタに書き込まれる。** そのため、同じ DCSG のチャンネル 2 も同時に
その高さで鳴る。チャンネル 2 を別のパートで使うなら、音符がぶつからない
ように書くこと。

`@0`〜`@2` のあいだは、ノイズのチャンネルの音符は鳴らすきっかけになるだけで、
高さは持たない。ノイズの種類（ホワイト／周期性）は `Y` で書く。

## ピッチベンドとポルタメント

### `P`*n* と `@P`*n*

`P`*n* は音の高さをセント単位でずらす（100 セントが半音）。`@P`*n* は今の値に
*n* を足す。`@P` は足していくので、合計は 1200 を超えられる。

**鳴っている音にもすぐ効く。** `@W` と組み合わせると音を曲げられる。

```
O4 C0 @W4 @P50 @W4 @P50 @W4 @P50 @W4 R0     ; 50 セントずつ上げる
```

### `~`*n*

`~` のあとの音符へ、**その音符の長さをかけて滑らかに移る。** 音符が終わる
ちょうどそのときに着く。

| 書き方 | 始まる高さ | 鳴らし直すか |
|---|---|---|
| `~`*n* `C4` | `C` から *n* セントずれた高さ | 鳴らし直す |
| `~ C4`（数なし） | 今鳴っている高さ | 鳴らし直さない |
| `~0 C4` | ―― | 普通の音符と同じ |

```
O4 C4 ~E4           ; C から E へ、四分音符かけて上がる
O4 ~-1200 C4        ; 1オクターブ下から C へしゃくり上げる
O4 C0 ~E4           ; 長さ 0 の C から E へ。始まりの高さを音名で書ける
```

- 数なしの `~` で、鳴っている音が無ければ普通の音符として鳴る
- **休符は `~` を捨てる。** `~` が届くのは次の音符だけ
- `P` と `@P` で決めたベンドとは別に足される。滑り終わったあともベンドは残る
- 滑り切る前に次の `~` が来たら、そのとき鳴っている高さから次へ向かう

## タイとレガート `&`

`&` は**前の音符と次の音符をつなぐ。** 次の音符は鳴らし直さない。

- 前後が**同じ高さ**ならタイ。鳴り続けたまま長さがつながる
- 前後が**違う高さ**ならレガート。鳴らし直さずに高さだけが変わるので、
  音の立ち上がりがやり直されない

```
O4 C4 & C4       ; 2分音符として鳴る
O4 C4 & E4       ; C から E へ、鳴らし直さずに移る
```

- **`Q8` 以外では効かないことがある。** `Q` が 8 より小さいと、前の音符が途中で
  止まってしまい、つなぐ相手が残っていない。そのときは次の音符が普通に鳴る
- 休符は `&` を捨てる
- **行の終わりに `&` を書くと、次の同じトラックの行の最初の音符へつながる。**
  小節をまたぐタイはこう書ける

## 繰り返しと記号

| コマンド | 意味 |
|---|---|
| `\|:` | 繰り返しの始まり。**入れ子は4段まで** |
| `:\|`*n* | 繰り返しの終わり。**始まりからここまでを全部で *n* 回演奏する**。*n* を省くと 1。0 は終わらない |
| `[`*n* | 繰り返しの *n* 回目だけ演奏する区間（ブロック）を始める。*n* は省けない |
| `]` | ブロックを閉じる。省ける（下記） |
| `(*)`*n* | セーニョ。*n* は 0〜3、省くと 0 |
| `(DS)`*n* | ダルセーニョ。セーニョ *n* へ戻る。*n* を省くと 0 |
| `(TC)`*n* | トゥコーダ。*n* 回目にここへ来たとき、コーダへ飛ぶ。*n* を省くと 2 |
| `(CODA)` | コーダ。1つのトラックに1つ |
| `(FINE)`*n* | フィーネ。*n* 回目にここへ来たとき、演奏を終える。*n* を省くと 2 |
| `(DC)` | ダカーポ。曲の頭へ戻る |

### ブロック（1番カッコ・2番カッコ）

ブロックは `[`*n* で始まり、**`]`・次の `[`・繰り返しの終わり `:|` のどれかで
終わる。** 並んだブロックが1つの組になり、組はブロックが終わったあと次が `[`
でなければそこで終わる。

```
|: ABC [1 D [2 E :|2         ; 1回目 ABC D、2回目 ABC E
|: ABC [1 D ] [2 E ] F :|2   ; 1回目 ABC D F、2回目 ABC E F
```

- **周回に合うブロックが無ければ、組の最後のブロックを演奏する。** エラーには
  ならない
- 1つの繰り返しの中に、組を2つ以上置いてもよい。番号はそれぞれの組の中で数える
- **ブロックの組の中に `|:` は置けない。** 組を閉じてからなら置ける
  （`|: A [1 B ] C |: D :|2 :|2` は通る）

### セーニョ・コーダ・フィーネ・ダカーポ

- **`(TC)` と `(FINE)` は、そこへ来た回数を数えて、*n* 回目に効く。** 数は
  曲を頭から始めたときにだけ 0 に戻り、繰り返しやダカーポでは戻らない。
  ダカーポで曲の頭へ戻った1周目の終わりの `(TC)` が1回目、2周目が2回目になる
- `(TC)0` は 256 回目に効く。数は 256 回で一周する
- **対応するセーニョの無い `(DS)` と、コーダの無いトラックの `(TC)` は無視される**
- `(DS)` はセーニョへ戻るだけで、それより後ろに書いたセーニョへは飛ばない
- **`(DC)` と `(FINE)` は、そのトラックだけでなくシーケンス全体の演奏を
  終わらせる。** そのあとどうなるかは、演奏を始めるときの繰り返しの指定で決まる
- `(DS)` と `(TC)` で飛ぶと、繰り返しの入れ子は捨てられる。飛んだ先で入った
  繰り返しは1回目から数える

### 書き方の細かいこと

- **繰り返しとブロックの組は、そのトラックの中で閉じていること。** 閉じずに
  トラックが終わるとエラー。行が分かれていてもよい
- `:|` に対応する `|:` が無い、`]` に対応する `[` が無い、はエラー
- 1つのトラックの `(TC)` と `(FINE)` は合わせて8個まで
- **音符も休符も無い無限の繰り返しは、演奏するとそのトラックがそこで終わる。**
  `|: :|0` のように時間を取らない繰り返しは、エラーにはならない

## SSGS のエンベロープと定位

`S`・`M`・`I` は SSGS のためのコマンド。**ほかの音源のトラックに書いても
エラーにならず、何も起きない。** ある音源のために書いた譜面を別の音源で
鳴らしても止まらないようにしてある。

| コマンド | 意味 |
|---|---|
| `S`*n* | ハードウェアエンベロープの形（0〜15） |
| `M`*n* | ハードウェアエンベロープの周期（1〜65535） |
| `I`*n* | 定位。0 が左端、8 が中央（両側とも最大）、15 が右端 |

ハードウェアエンベロープを鳴らすには、`@`*n* で bit4 を立てる
（[SSGS の `@n`](#ssgs)）。

## レジスタへの直接の書き込み `Y`

`Y`*r*`,`*d* は、そのトラックの音源のレジスタ *r* に *d* を書く。時間を取らない。
**レジスタ番号はどの音源でもチップ自身のもの**で、2つある音源のどちらに届くかは
`#assign` のデバイスで決まる。

| 音源 | 書けるレジスタ *r* | *d* |
|---|---|---|
| SSGS | `$00`〜`$0D`（1組目）、`$20`〜`$2D`（2組目） | 0〜255 |
| OPLLEX | `$00`〜`$07`、`$0E`〜`$18`、`$20`〜`$28`、`$30`〜`$38`、`$40`〜`$48`（バンク） | 0〜255 |
| OPL2EX | `$00`〜`$FF`。ただし **`$04` は書けない**（下記） | 0〜255 |
| DCSG | 0〜7（下記） | 0〜15 |
| SCC | `$00`〜`$FF`（レジスタの窓の先頭からの位置） | 0〜255 |

**範囲の外はエラー。** リズムと ADPCM のトラックも、そのチャンネルの音源の
表に従う。

**SSGS は、どちらの組に書くかもレジスタ番号で決まる。** トラックの
チャンネルが組を選ぶことはない。

### 第3引数のマスク

`Y`*r*`,`*d*`,`*m* と書くと、レジスタ *r* は次の値になる。

```
r ← (r の今の値 AND m) OR d
```

*m* のビットが 1 の桁は今の値が残り、0 の桁は *d* になる。1つのレジスタに
いくつかの設定が詰まっているとき、変えたい桁だけを書ける。*m* を省くと 0 と
同じで、レジスタ全体が *d* になる。

```
Y$30,$50,$0F    ; OPLLEX の音色だけを 5 に変え、音量は残す
```

**今の値には、音符や音量が書いたものも含まれる。** Y8960 の音源はどれも
レジスタを読み出せないので、書いた値の控えから求める。

音符・`V`・`@` は、次に働いたとき、自分の受け持つビットを書き直す。

### DCSG のレジスタ番号

DCSG にはレジスタの番地が無く、1バイトの中に番号と値が入る。*r* はその番号で、
*d* は 4 ビット。

| *r* | 内容 |
|---|---|
| 0 / 2 / 4 | チャンネル 0 / 1 / 2 の周波数の**下位4ビット** |
| 1 / 3 / 5 | チャンネル 0 / 1 / 2 の減衰 |
| 6 | ノイズの制御（種類と高さ） |
| 7 | ノイズの減衰 |

周波数の上位6ビットは `Y` では書けない。高さは音符で書く。

### OPL2EX の `$04` を書けないわけ

`$04` は割り込みの許可を決めるレジスタで、ADPCM の2つの割り込みは常に止めて
おかなければならない。許すとカートリッジが割り込みを出し続け、エラーも出ない
まま機械が止まる。

## 名前の参照 `=名前;` と `X名前;`

`#define` で付けた名前を MML の中から使う。`#define` の書き方は
[`mml-source.md`](mml-source.md) にある。

- **`=名前;` は数。** MML で数を書くところならどこにでも書ける。`O=OCT;C` は
  名前 `OCT` の数をオクターブにしてから C を鳴らす
- **`X名前;` は MML。** その場に展開する。展開の前に決めた長さ・音量・
  オクターブはそのまま効く。**後ろに続けて MML を書ける**
- 名前は `;` で閉じる。閉じないとエラー
- **`X名前;` の中でさらに `X` を使えるのは 8 段まで。** 名前が自分を指すと
  終わらないため

## ADPCM 用 MML

OPL2EX のチャンネル 9 のトラックは、**ふつうの MML と同じ書き方**をする。
違うのは次のコマンドの意味だけ。

| コマンド | ADPCM での意味 |
|---|---|
| `@`*n* | ボイスファイルの番号（0〜63）を選ぶ。番号は `#pcmbank` が付けたもの（[`mml-source.md`](mml-source.md)） |
| 音符・`N`*n* | そのボイスファイルを鳴らす。**高さで再生の速さが変わる** |
| `R`*n* | 鳴らすのを止める |
| `V`*n*・`@V`*n* | 出力の大きさ |

**`O5 E` が、ボイスファイルのサンプリング周波数そのままで鳴る高さ。** そこから
半音ずれるごとに、再生の速さが 2 の 12 乗根倍になる。実際の周波数が 49716Hz を
超える高さでは頭打ちになる。

`L`・`O`・`T`・`Q`・`>`・`<`・`.`・`{ }`・`=名前;`・`X名前;` はふつうの MML と同じ。
音色・ピッチベンド・エンベロープに関するコマンドは無視される。

## リズム音用 MML

OPLLEX・OPL2EX のチャンネル 10 のトラックは、**別の書き方をする。** 1つの
トラックで複数の楽器を同時に鳴らすため、鳴らしたい楽器を並べ、そのうしろに
長さを書く。

| 文字 | 意味 | 範囲 | 既定 |
|---|---|---|---|
| `B` | バスドラム | | |
| `S` | スネアドラム | | |
| `M` | タムタム | | |
| `C` | シンバル | | |
| `H` | ハイハット | | |
| `!` | 直前の楽器を、アクセントの音量で鳴らす | | |
| *n* | 並べた楽器を鳴らし、*n* 分音符ぶん待つ | 1〜96 | 4 |
| `V`*n* | アクセントの付かない音量 | 0〜15 | 8 |
| `@A`*n* | アクセントの付く音量 | 0〜15 | 15 |
| `@V`*n* | `V` と同じものを 0〜127 で | 0〜127 | |

```
T120 V10 @A14 BSH8 H8 S!H8 H8
```

- バス・スネア・ハイハットを鳴らし、8分音符ぶん待つ
- ハイハットを鳴らし、8分音符ぶん待つ
- スネアをアクセントを付けてハイハットと鳴らし、8分音符ぶん待つ
- ハイハットを鳴らし、8分音符ぶん待つ

楽器の並びの長さを省くと四分音符になる。ただしトラックの最後の並びには
長さが要る。

`T`・`R`・`Y`・`.`・`=名前;`・`X名前;`、それに繰り返しと記号は、ふつうの MML と
同じ。**`L` は無い。** `@` は `@A` と `@V` だけ。

- 楽器は鳴らすたびに減衰するので、**音を止める書き方は無い。** `Q` も無い
- OPLLEX と OPL2EX で、**同じ `V` が同じ音量になる**
- リズムのチャンネルを使うあいだ、同じブロックのチャンネル 6〜8 はリズムの
  ために使われる（[`mml-source.md`](mml-source.md) の `#assign`）

## 出せない高さ

`O1`〜`O8` のすべてがどの音源でも出せるわけではない。**範囲の外はエラーに
ならず、出せる範囲の端で鳴る。**

| 音源 | 出せないところ | 鳴り方 |
|---|---|---|
| OPLLEX・OPL2EX | `O8` の `G` から `B` | 出せるいちばん高い音 |
| OPLLEX・OPL2EX | `O1` より下（`N0`〜`N11` やピッチベンドで届く） | 鳴らない |
| SSGS・DCSG・SCC | 周波数の値が入りきらない低い音・高い音。DCSG は `O2` の `C` から下 | 出せる端の音 |

ピッチベンドやポルタメントで範囲の外へ出たときも同じ。
